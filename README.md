# Smart-Super-Shop-Billing-System
Assembly Language Shopping System

## Project Overview

Smart Super Shop Billing System is an Assembly Language project developed using 8086 Assembly. It simulates a simple shopping and billing system where users can select products, enter quantities, calculate bills, and receive discounts.

## Features

- Department Selection
- Product Selection
- Quantity Input
- Automatic Bill Calculation
- Discount Calculation
- Lucky Draw System
- Final Bill Receipt

## Departments and Products

### 1. Daily Essentials

- Sugar – 80 TK
- Salt – 25 TK

### 2. Cold Drinks

- Mango Drink – 35 TK
- Lemon Water – 20 TK

### 3. Snack Corner

- Crackers – 45 TK
- Popcorn – 30 TK

## Discount System

- Above 1000 TK: 20% Discount
- Above 500 TK: 10% Discount
- 500 TK or Below: No Discount

## Lucky Draw

- Box 1: 5% Extra Discount
- Box 2: 10% Extra Discount
- Box 3: No Extra Discount

## Technologies Used

- 8086 Assembly Language
- DOS Interrupt (INT 21H)
